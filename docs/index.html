octave_mermaid_js文档
欢迎广大开发者将此文档翻译为其他语言。
软件源安装

octave_mermaid_js可以通过Octave软件源安装。

通过Octave软件源安装octave_mermaid_js，代码如下：

>> pkg install -forge octave_mermaid_js

在线安装

octave_mermaid_js可以在线安装。

在线安装octave_mermaid_js，代码如下：

>> pkg install 'https://github.com/CNOCTAVE/octave_mermaid_js/releases/download/2.0.0/octave_mermaid_js.tar.gz'

源码安装

octave_mermaid_js可以直接使用tar包安装。

假设你下载的源码包名为octave_mermaid_js.tar.gz，源码安装的代码如下：

>> pkg install octave_mermaid_js.tar.gz -local

如何使用
在安装后，加载octave_mermaid_js即可使用，代码如下：

>> pkg load octave_mermaid_js

依赖库
自 v2.0.0 起，octave_mermaid_js 不再调用远程 Web API，而是把 mermaid.js 以 vendor 的形式内置到软件包中（位于 ./vendor/mermaid.min.js），并在本地用 Node.js 驱动一个无头 Chromium（C++ 实现的 V8 JavaScript 运行时 + Blink 排版引擎）来渲染图片。因此运行时的依赖变为：
1. Node.js（提供 V8 JavaScript 运行时）。
2. 一个 Chromium / Chrome 浏览器（无头渲染）。
3. Node 依赖 puppeteer-core（在软件包目录执行 npm install 安装）。
不同的 Linux 发行版安装命令有所不同。Fedora 示例：

$ sudo dnf install nodejs chromium-headless

$ cd octave_mermaid_js && npm install

如果你的 Chromium 不在标准路径，可用 CHROMIUM_PATH 环境变量指定其可执行文件路径。欢迎广大开发者补充其他发行版的安装命令。
函数用法
mermaid_js_imshow

[ret, status] = mermaid_js_imshow (GRAPH)

输入Markdown格式的图GRAPH，显示图片。

返回内部输出ret和图片生成状态status。

如果status=0，则代表图片生成成功，否则代表图片生成失败。

如果图片生成失败，那么将显示失败或显示错误的图片。

mermaid_js_save

[ret, status] = mermaid_js_save (GRAPH, FILE_PATH)

输入Markdown格式的图GRAPH和保存图片的文件名FILE_PATH，保存图片。

返回内部输出ret和图片生成状态status。

如果status=0，则代表图片生成成功，否则代表图片生成失败。

如果图片生成失败，那么将保存失败或保存错误的图片。

常见用例
保存并显示Markdown图，代码如下：
graph = {
    "graph LR;"
    "    A--> B & C & D"
    "    B--> A & E"
    "    C--> A & E"
    "    D--> A & E"
    "    E--> B & C & D"
};
graph = strjoin(graph, "\n");
[ret, status] = mermaid_js_save(graph, "result.png")
[ret, status] = mermaid_js_imshow(graph)

流程图的文档详见：

https://mermaid.js.org/syntax/flowchart.html

graph = flowchart LR
    Start --> Stop
>> mermaid_js_imshow(graph)
